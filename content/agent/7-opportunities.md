# 7 — Other money opportunities

Keywords and audiences that don't bring agency clients can still bring money. Never discard them: log them, and Houssam decides.

## How to spot one
- Score verdict LATER because of **intent**, not difficulty: people who want to *learn* or *start* something (courses, "how to start", "for beginners"), want a **free tool/template**, a **job**, or are **other agencies**.
- Briefing items with a "productizable" angle (a template everyone needs, a checklist, a recurring question).
- Example: "ai automation agency" (US 4,400/mo, KD 19) = mostly people who want to START an AI agency (courses, Liam Ottley) → course / coaching / templates / YouTube.

## Where it goes: Notion database "💰 Opportunities" (in the Intelligence Hub)
Data source: `collection://faf4bd38-582c-458a-a386-4e7253ab53a2` (database https://app.notion.com/p/e3ae199eac1240d2828d49cc64fc73bd). Use the Notion tools: query/search it, then create pages with that data source as parent.
Search it first (no duplicates: same audience/need = update the existing row's Proof instead). New row fields:
- **Opportunity** (title) · **Audience** · **Proof** (keywords + volume/KD per market, source) · **Volume** (best monthly volume) · **KD** · **Markets** · **What we sell** (Course, Coaching/Consultation, Templates, YouTube video, Lead magnet, Service page, Other) · **Effort** (S/M/L) · **Estimated value** (simple math, e.g. "4,400 × 1% × €300") · **Status** = 🆕 New · **Found** (date) · **Source** (score run / GSC / briefing) · **Next step** (the first concrete action).
Never build anything for an opportunity whose status isn't ✅ Go.

## Playbooks when Houssam sets ✅ Go (validate before building)
- **YouTube video** → write the brief: title on the keyword, hook, outline, on-screen demo, description with links to the site page, chapter list. The matching blog post embeds the video and links to the channel @weautomationagency.
- **Course / coaching** → first a simple waitlist / "book a call" page (one page, no product yet) + 1 post or video pointing to it. Build the product only if people sign up.
- **Templates (Make/n8n)** → a free template in exchange for an email (lead magnet) → newsletter → leads. Real, tested templates only.
- **Consultation** → a "book a call" option on /start with its own price.
- **Service page** → a new page only if the intent is buying a service we really offer.
Then status 🔨 In progress → 🟢 Live, and record the result (signups, views, sales) in the row.
